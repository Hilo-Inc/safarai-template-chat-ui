# Chat UI

A ChatGPT-style interface for your own API keys.

Launch it on your own server from the Safarai template gallery, or build it
anywhere: `docker build .`.

Runs the official Open WebUI image. This repo (Dockerfile and docs) is MIT, see LICENSE; Open WebUI itself is under its own license: https://github.com/open-webui/open-webui/blob/main/LICENSE
